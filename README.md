# 贡塘王统记——吐蕃君主天子赞普世系于阿里下部贡塘源流·水晶幻化明镜史

     《贡塘王统记——吐蕃君主天子赞普世系于阿里下部贡塘源流·水晶幻化明镜史》作为18世纪著名学者噶陀·仁增才旺诺布的重要历史著作,是研究西藏西部古老王国——芒域贡塘最核心的法统与地缘政治文献。由于历史变迁与战乱动荡,该书的木刻本及本土写本在长达数百年的历史中散佚难寻。
      幸运的是,这份曾流散于海外的珍贵书稿,最终被佛教数字资源中心(BDRC,Buddhist Digital Resource Center)成功采集并进行数字化保存。笔者正是通过 BDRC 平台有幸获取了这一珍贵的藏文扫描件,将其完整翻译为中文。
